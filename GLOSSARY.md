# DOA2 Ultimate Native Port

The language for the native port of Dead or Alive 2 Ultimate and the host
services that replace the Xbox libraries.

## Graphics

**Authentic look**:
The game's original art direction, shown at host resolution and precision.
Content, lighting and effects stay as the game draws them.
_Avoid_: Original graphics, vanilla

**Enhancement**:
A host-side change that makes the image cleaner or sharper while it keeps the
authentic look.
_Avoid_: Improvement, mod, upgrade

**Accuracy fix**:
A host change that makes the image match what the game asks the hardware for,
such as filtering or mip levels it requested and the host ignored.
_Avoid_: Bug fix, enhancement

**Presenter-only**:
Describes an enhancement that changes only the host image and never guest
state, so peers with different settings stay in sync in netplay and replays.
_Avoid_: Cosmetic, client-side
